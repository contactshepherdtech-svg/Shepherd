# Contributing to Shepherd

First off — thank you for your interest in contributing  
We appreciate any help in improving this project.

---

## ✅ Contribution Guidelines

By contributing to this repository, you agree to the following terms:

### 1. Voluntary Contributions
All contributions are made **voluntarily** and without expectation of:
- compensation
- salary
- payment
- equity
- ownership stake in the business or product

---

### 2. No Ownership or Equity
Contributing to this project **does not grant you**:
- ownership in the codebase
- intellectual property ownership
- shares, stock, or equity
- co-founder status

All project ownership remains with the repository owner.

---

### 3. License Grant
By submitting a contribution (pull request, issue, code, or documentation), you agree that:

- Your contribution may be used, modified, distributed, and commercialized by the project owner
- You grant the project owner a **perpetual, worldwide, non-exclusive, royalty-free license** to use your contributions

---

### 4. No Obligation
The project owner:
- is **not obligated** to accept contributions
- is **not obligated** to provide compensation now or in the future
- may modify or remove contributions at any time

---

### 5. Future Opportunities
If the project evolves and opportunities arise:
- roles, compensation, or equity (if any) will be **separately discussed and agreed upon in writing**
- contributions made prior do **not imply entitlement**

---

### 6. Code Standards
Please:
- write clean, readable code
- follow existing project structure
- include comments where necessary
- test your changes when possible

---

## ✅ How to Contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request

---

## ✅ Code of Conduct

Be respectful and constructive.  
We aim to maintain a positive and collaborative environment.

---

## ✅ Questions?

If you have questions, feel free to open an issue.
